# Modulo-3-Programacion-4
# Biblioteca Personal con MariaDB y SQLAlchemy

## Objetivo
Adaptar la aplicación de biblioteca personal para utilizar MariaDB como sistema de gestión de base de datos, implementando SQLAlchemy como ORM para un manejo orientado a objetos.

---

## Funcionalidades
- Agregar nuevo libro  
- Actualizar información  
- Eliminar libro  
- Ver listado completo  
- Buscar por título, autor o género  
- Salir del programa

---

## Requisitos del entorno
- Python 3.8 o superior  
- MariaDB instalado y en ejecución  
- Dependencias de Python listadas en `requirements.txt`

---

## Instalación de dependencias
Ejecutar en la terminal:

```bash
pip install -r requirements.txt
